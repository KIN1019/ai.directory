# Hospital Authority Frontend Development Context

This context provides comprehensive guidelines and best practices for developing frontend applications within the Hospital Authority ecosystem.

## Tech Stack

- React 18+ with TypeScript
- Next.js 14+ for server-side rendering
- Tailwind CSS for styling
- CMS Design System components

## Development Standards

- Follow Hospital Authority coding standards
- Implement accessibility features (WCAG 2.1 AA compliance)
- Ensure mobile responsiveness
- Use type-safe development practices

## Security Considerations

- Implement proper authentication using HA SSO
- Follow OWASP security guidelines
- Sanitize all user inputs
- Use HTTPS for all API calls
