# Java Microservice Development Context

This context provides guidelines for developing Java-based microservices using Spring Boot.

## Tech Stack
- Java 17+
- Spring Boot 3.x
- Spring Cloud for microservice patterns
- PostgreSQL/Oracle for data persistence

## Architecture Patterns
- Follow Domain-Driven Design principles
- Implement Circuit Breaker pattern for resilience
- Use API Gateway for routing
- Implement proper service discovery

## Best Practices
- Write comprehensive unit tests (80%+ coverage)
- Use SonarQube for code quality
- Implement proper logging and monitoring
- Follow 12-factor app principles
