# Mobile App Development Context

This context provides guidelines for developing cross-platform mobile applications.

## Tech Stack Options

### React Native
- React Native 0.72+
- Expo SDK 49+
- TypeScript for type safety
- React Navigation for routing

### Flutter
- Flutter 3.0+
- Dart programming language
- Material Design components

## Development Standards
- Responsive design for various screen sizes
- Offline-first architecture
- Performance optimization for low-end devices
- Platform-specific UI guidelines (iOS Human Interface Guidelines, Material Design)

## Testing Strategy
- Unit tests for business logic
- Integration tests for API calls
- UI tests using Detox (React Native) or Flutter Test
- Manual testing on physical devices
