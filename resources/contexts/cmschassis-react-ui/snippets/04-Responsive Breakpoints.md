# Responsive Breakpoints

Breakpoints set a visual point on the screen to accommodate responsive design and ensure a consistent, optimized experience across screen widths. As breakpoints change, content shift around to fit the adjusted layout. Use this set of standard breakpoints to maintain layout integrity across screen sizes.

For better results, test designs and code at each of these standard breakpoints.

## Breakpoint

### Breakpoint Name: SM

- Screen Width: 768 - 1250px
- Layout Column: 12 Columns
- Margin: 20px
- Gutters: 16px
- Typical Devices: iPad (Landscape)

### Breakpoint Name: MD

- Screen Width: 1251 - 1650px
- Layout Column: 12 Columns
- Margin: 20px
- Gutters: 16px
- Typical Devices: Desktop

### Breakpoint Name: LG

- Screen Width: >1651px
- Layout Column: 12 Columns
- Margin: 20px
- Gutters: 16px
- Typical Devices: Large Desktop
