# Welcome to the cms-common-schedulerfwk wiki!
Welcome to the CMS Common Scheduler framework Documentation. This library provides a robust and flexible way to manage scheuled tasks in Spring boot 3.X application with using Quartz Scheduler.

A [Quick Start](https://hagithub.home/CMSCHASSIS/cms-common-schedulerfwk/wiki/Quick-Start) guide is provided to offer a simple kickstart on how to use the libraries

# Modules
cms-common-schedulerfwk - library to handle scheduling

# Quick Deploy to SIT env
1. **Clone and Modify Sample Application**  
   Clone the [cms-common-schedulerfwk-sample](https://hagithub.home/CMS/cms-common-schedulerfwk-sample) and make necessary modifications in application.yml for the product.

2. **Create Database Schema**  
   Refer [Support DB DDL](https://hagithub.home/CMSCHASSIS/cms-common-schedulerfwk/wiki/Support-DB-DDL) to create necessary table in the product database.

3. **Deploy SIT Environment**  
   Execute the GitHub workflow to deploy the SIT(CORP) environment.
