# Resources Directory

Content and data files for the AI Directory platform. Contains structured data that powers the website's three main sections.

## Structure

**`contexts/`** - Development contexts for AI coding agents with project guidelines, standards, and code snippets

**`mcp/`** - Model Context Protocol (MCP) server configurations and tool definitions

**`rules/`** - Prompt templates and rules for AI agent behaviors and coding guidelines

## Content Guidelines

Each directory contains its own README.md with detailed format specifications and examples. All tags must be defined in respective `tags.yaml` files before use. Use kebab-case naming for files and directories.
