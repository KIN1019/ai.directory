# PostgreSQL Type Validator

A TypeScript library for parsing and validating PostgreSQL data types using ANTLR4.

## Scripts Usage

The `scripts/` directory contains TypeScript utilities for analyzing and comparing PostgreSQL schema column types across different schema files.

### compare-columns.ts

Compares column types across three JSON schema files (CP7, HPI, and HKPMI) to identify data type mismatches.

**Purpose**: Identifies columns with the same name but different data types across schema files, helping detect inconsistencies in database schema definitions.

**Usage**:

```bash
npx tsx scripts/compare-columns.ts
```

**Input Files** (automatically read from `contexts/` directory):

- `column-types-hpi.json`
- `column-types-hkpmi.json`

**Output**:

- `contexts/column-mismatches.json` - Detailed JSON report of all column type mismatches
- Console output showing summary and first few mismatched columns

**Output Format**:

```json
[
	{
		"filename": "patient.sql",
		"table_name": "patient",
		"column_name": "patient_key",
		"data_type": "char(8)",
		"mismatches": [
			{
				"file": "patient.sql",
				"table": "patient",
				"type": "varchar(16)"
			}
		],
		"possible": ["char(8)", "varchar(16)"]
	}
]
```

### find-conflict-type.ts

Analyzes a single schema file to find columns with the same name but different data types within that schema.

**Purpose**: Detects internal inconsistencies within a single schema where columns with identical names have different data types across different tables.

**Usage**:

```bash
npx tsx scripts/find-conflict-type.ts
```

**Input**:

- `contexts/column-types-hpi.json` (hardcoded input file)

**Output**:

- `contexts/conflict-types.json` - JSON report of conflicting column types within the schema
- Console output showing count and list of conflicting columns

**Output Format**:

```json
[
	{
		"columnName": "hospital_code",
		"conflict": [
			{
				"type": "char(3)",
				"foundIn": [
					{ "file": "patient.sql", "table": "patient" },
					{ "file": "case.sql", "table": "pmi_case" }
				]
			},
			{
				"type": "varchar(6)",
				"foundIn": [{ "file": "hospital.sql", "table": "hospital" }]
			}
		]
	}
]
```

## Auto-generated ANTLR Code Files

The files in `src/syntax/antlr/` are automatically generated by the ANTLR VS Code extension when the grammar file (`PostgreSQLDDL.g4`) is saved. **DO NOT EDIT THESE FILES DIRECTLY** - any changes will be overwritten when the grammar is recompiled.

To regenerate these files:

1. Make changes to `PostgreSQLDDL.g4`
2. Save the file
3. The extension will automatically regenerate all required parser/lexer files
