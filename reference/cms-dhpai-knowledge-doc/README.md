# cms-dhpai-knowledge-doc

HA knowledge base, coding standards, coding conventions and security compliance for DHPAI Context MCP.

## Overview

This knowledge base repository serves as the central hub for HA organizational standards, best practices, and compliance guidelines.

## Knowledge Base Content

This repository contains the following types of organizational knowledge:

- **ChangeManagement/**: Change control processes, approval workflows, change request templates, and best practices for managing code modifications and deployments.

- **Coding/**: Programming standards and best practices organized by technology stack:
  - **General/**: Testing strategies, code review guidelines, performance optimization techniques applicable across all technologies.
  - **React/**: React-specific coding conventions, component design patterns, state management best practices, and usage examples.
  - **Springboot/**: Java/Springboot coding conventions, application architecture patterns, dependency injection guidelines, and code examples.

- **General/**: Organization-wide guidelines including onboarding procedures, development standards, FAQ, and cross-functional guidelines.

- **PrivateCloud(ECP)/**: Enterprise Cloud Platform documentation covering:
  - **Architecture/**: System design decisions, architecture diagrams, and technology choices.
  - **Compliance/**: Regulatory requirements, compliance checklists, and audit procedures.
  - **Deployment/**: Deployment procedures, runbooks, scripts, and infrastructure provisioning guides.
  - **Documentation/**: API specifications, infrastructure documentation, and architectural overviews.
  - **Security/**: Security hardening guides, security policies, and incident response procedures.
  - **Testing/**: Test plans, test strategies, and documented test cases.

- **Security/**: Organization-wide security knowledge including security policies, vulnerability management procedures, best practices for secure coding, and incident response guidelines.
